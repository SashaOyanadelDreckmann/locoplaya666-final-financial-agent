# PDF Policy (Costo Bajo + Calidad Editorial)

## Reglas obligatorias
- El agente principal NO debe generar PDFs directamente por MCP.
- La preparación del contenido para PDF debe delegarse a un agente barato tipo Haiku que:
  - resuma la respuesta final del agente principal,
  - incorpore contexto de intake del usuario,
  - entregue estructura editorial lista para render.

## Estándar visual del PDF
- Estilo: editorial moderno, minimalista premium (referencia NYT + Apple).
- El contenido debe usar el ancho útil completo de la hoja (sin “marco blanco” excesivo).
- Debe mantener espaciado superior limpio en cada nueva página (evitar texto pegado al borde).
- Evitar cortes feos entre bloques: respetar saltos de página y mantener secciones ordenadas.
- Permitir gráficos integrados entre secciones de texto para mejorar comprensión.

## Calidad mínima
- PDF sin errores de layout, tipografía consistente y jerarquía clara.
- Salida profesional, simple y legible, priorizando claridad editorial.
