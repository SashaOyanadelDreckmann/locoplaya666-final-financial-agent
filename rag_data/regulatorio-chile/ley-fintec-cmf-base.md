# Ley Fintec 21.521 y CMF - Base regulatoria

Este documento sirve como base de conocimiento regulatoria para respuestas del agente financiero en Chile.

## Ley 21.521 (Ley Fintec)

- La Ley N.21.521 promueve la competencia e inclusion financiera mediante innovacion y tecnologia en servicios financieros.
- Su Titulo III regula el Sistema de Finanzas Abiertas (SFA).
- El SFA habilita intercambio de informacion financiera con consentimiento expreso del cliente.
- El intercambio se realiza mediante interfaces de acceso remoto y automatizado.
- La normativa exige estandares de seguridad, privacidad e interoperabilidad.

## Principios del Sistema de Finanzas Abiertas

Principios clave que el agente debe considerar cuando explique la ley:

- Proporcionalidad
- Calidad de datos
- Transparencia e informacion al cliente
- Seguridad y privacidad de datos
- Trato no discriminatorio
- Interoperabilidad

## Rol de la CMF

- La Comision para el Mercado Financiero (CMF) regula y fiscaliza entidades del mercado financiero chileno.
- En materia Fintec y SFA, la CMF dicta normas de caracter general para implementacion tecnica y operativa.
- La implementacion normativa del SFA se ha comunicado por la CMF como un proceso por niveles y etapas.

## Glosario base CMF (terminos minimos)

- CMF: Comision para el Mercado Financiero.
- SFA: Sistema de Finanzas Abiertas.
- IPI: Institucion Proveedora de Informacion.
- IPC: Institucion Proveedora de Cuentas.
- Consentimiento expreso: autorizacion del cliente para compartir datos.
- Interoperabilidad: capacidad de instituciones para intercambiar datos de forma estandarizada.
